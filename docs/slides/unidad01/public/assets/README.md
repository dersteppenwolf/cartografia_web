# Directorio reservado para recursos históricos

Las capturas extraídas de `01_Fundamentos/01_Fundamentos_Internet.pdf` se
eliminaron del árbol de trabajo después de completar esta migración. No se
versionan ni se publican. El PDF de origen permanece disponible para consulta
histórica.

Si una revisión de migración necesita inspeccionar de nuevo una imagen, siga
`docs/slides/Readme.md` y extraiga los recursos a un directorio temporal fuera
del repositorio. No incorpore una captura al material mantenido sin resolver
procedencia, licencia, texto alternativo y utilidad pedagógica.

`vite.config.mts` usa `public-generated/` como directorio público de Slidev. La
presentación modernizada solo publica diagramas propios desde
`public-generated/assets/generated/`.
