# Unidad 8. Operación y publicación

Una publicación responsable empieza por validar contenido, datos, dependencias y
el cliente local. El sitio estático se publica como un artefacto ensamblado; la
base de datos y GeoServer son referencias locales y no requieren cuentas del
alumnado.

La recuperación local restaura PostGIS desde un backup verificado y vuelve a
configurar GeoServer con los scripts versionados. No se copia el directorio de
datos de GeoServer como configuración.

Consulta las guías de [seguridad]({{ '/guias/seguridad/' | relative_url }}),
[publicación]({{ '/guias/publicacion/' | relative_url }}),
[restauración]({{ '/guias/restauracion/' | relative_url }}) y
[accesibilidad]({{ '/guias/accesibilidad/' | relative_url }}).
