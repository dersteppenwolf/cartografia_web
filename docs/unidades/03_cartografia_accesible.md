# Unidad 3. Cartografía accesible y UX

Un mapa temático debe explicar qué representa, cómo se clasifican los datos, qué
incertidumbre existe y qué decisiones cartográficas condicionan su lectura. No
se usa solo el color para comunicar una diferencia: leyenda, texto, patrones,

El objetivo es WCAG 2.2 AA dentro del alcance controlado: teclado, foco visible,
reflow, contraste, nombres accesibles, mensajes de estado y alternativa de
datos. El mapa no reemplaza una tabla para quien no puede operar un canvas.

## Diagnóstico

Con el mapa básico abierto, usa solo teclado para llegar al selector y al mapa.
Luego reduce el ancho de la ventana a 320 CSS px y verifica que la tabla y la
leyenda siguen disponibles.
