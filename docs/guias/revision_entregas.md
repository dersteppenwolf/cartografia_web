# Revisión de entregas

Revisa cada entrega mediante la rúbrica aplicable y comprueba cartografía,
procedencia y licencia de datos, accesibilidad, privacidad, seguridad,
rendimiento, reproducibilidad y comunicación. La publicación debe incluir una
leyenda, atribución, mensaje de error comprensible y alternativa tabular o de
descarga para los hallazgos del mapa.

No se aprueba una entrega que incorpore datos sociales en cuarentena, secretos,
tokens activos, endpoints HTTP externos inseguros ni cuentas SaaS obligatorias.
