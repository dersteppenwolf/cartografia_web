# Prerrequisitos

El equipo de referencia tiene cuatro núcleos de CPU, 16 GB de RAM, SSD con 20 GB
libres y virtualización habilitada. Se requieren Git, Node.js 24 LTS, Python
3.12, Ruby 3.3.6 con Bundler 2.6.2 o Docker, Docker Compose, un navegador actual
con WebGL y acceso a los puertos locales documentados por cada ejemplo.

Las herramientas de software libre pueden instalarse en computadores personales
sin licencia adicional. El curso no requiere cuentas SaaS. Safari se verifica en
equipos macOS durante el piloto, pero no se exige a cada estudiante.

Cada unidad inicia con un diagnóstico breve y termina con un ejercicio
verificable. Si un equipo no cumple los recursos mínimos, se debe usar el perfil
ligero o un entorno institucional aprobado antes de convertir una práctica en
requisito.
