# Revisión de accesibilidad

Las pruebas Axe son apoyo, no una demostración completa de WCAG 2.2 AA. Revisa
manualmente teclado, foco visible, orden de foco, diálogo de consulta, zoom y
reflow al 200%, contraste, mensajes de carga/error, leyendas, atribución y la
tabla equivalente a cada mapa.

Durante el piloto, confirma esos flujos en Safari real sobre macOS. Playwright
WebKit detecta regresiones tempranas, pero no sustituye esa evidencia.
