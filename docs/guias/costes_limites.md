# Costes y límites

El curso no exige cuentas SaaS. La referencia local consume espacio para
imágenes Docker, dependencias y datos de práctica; revisa los 20 GB libres
indicados en los prerrequisitos antes de iniciar el stack.

Si una institución publica el sitio, debe revisar periódicamente almacenamiento,
transferencia, minutos de CI y límites del proveedor. PMTiles y COG requieren
HTTP Range y CORS; no se debe contratar un hosting sin comprobar ambas
capacidades contra el artefacto desplegado.
