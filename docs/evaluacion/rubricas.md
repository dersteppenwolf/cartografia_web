# Rúbricas

Las entregas se evalúan por comportamiento demostrable, no por capturas o URLs
aisladas. Cada criterio se califica como logrado, parcialmente logrado o no
logrado según la evidencia entregada.

## Criterios comunes

- Problema, fuentes, licencia, CRS, esquema y sensibilidad documentados.
- Procesamiento reproducible mediante scripts o instrucciones verificables.
- Cartografía con clasificación, leyenda, atribución, incertidumbre y límites.
- Accesibilidad WCAG 2.2 AA aplicable, teclado, foco, reflow y alternativa de
  datos.
- Seguridad sin secretos, tokens reales ni servicios personales obligatorios.
- Validación local, pruebas relevantes y documentación de resultados.

## Entrega 1

Se verifica que el mapa funciona localmente, presenta alternativas de datos y
explica sus decisiones cartográficas.

## Entrega 2

Se verifica que el stack se levanta desde un clon limpio, que WFS y OGC API -
Features describen la misma colección y que el estilo, SQL y salud del servicio
están documentados.

## Entrega 3

Se verifica que el build estático funciona, que la ruta PMTiles o COG está
justificada, que los errores son comprensibles y que el proyecto incluye
pruebas, accesibilidad, privacidad, arquitectura y límites operativos.
