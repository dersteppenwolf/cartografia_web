# Entrega 3. Aplicación geoespacial desplegable

Construye una aplicación TypeScript con filtros, consulta, narrativa, URL
compartible y mensajes de carga/error. Usa OGC API - Features y elige una ruta
de entrega: MVT/PMTiles para vector o COG para raster. Incluye STAC estático si
hay activos espaciotemporales.

Entrega el build estático, pruebas, evidencia de accesibilidad, evaluación de
privacidad y ética, arquitectura, atribuciones y límites conocidos. El backend
debe ser reproducible localmente; el despliegue full-stack es electivo o
institucional.
