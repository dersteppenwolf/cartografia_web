# Entrega 2. Servicio interoperable reproducible

Levanta PostGIS y GeoServer con Docker Compose. Carga una colección de ejemplo,
crea índices espaciales y roles de lectura, publica WFS y OGC API - Features
sobre la misma colección y aplica un estilo SLD. Incluye SQL, healthchecks,
pruebas de disponibilidad y el procedimiento para destruir volúmenes y
reconstruir el stack.

No se aceptan IPs históricas, credenciales reales ni configuración manual no
documentada.
