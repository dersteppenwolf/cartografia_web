# Entrega 1. Mapa publicable y accesible

Documenta un problema territorial y uno o dos datasets. Incluye fuente,
propietario, fecha o versión, licencia, CRS, esquema, sensibilidad y checksum.
El mapa debe cargarse por HTTP local, funcionar por teclado, mostrar foco,
leyenda, atribución, estado de carga/error y tabla, resumen o descarga
equivalente.

Explica atributos, clasificación, colores, escala, incertidumbre y límites de
interpretación. El código y el procesamiento deben poder repetirse sin usar una
cuenta SaaS.
